# Background joint-model computation

The page delegates the existing correlated model to a same-origin computation
worker. `source_call_conditioning.js`, `chamber_control_model.js` and
`national_county_likelihood.js` remain the numerical implementation. The worker
uses the same prepared basis, accepted envelopes, fixed 3,000 simulations,
seed, no-credit Independent accounting, fixed count target and hard ESS floor.
This changes scheduling and admission, not calibration or source eligibility.

## Exact assets and atomic frames

The worker imports six fixed, fingerprinted local helper/model files. A nested
asset check updates their identities before the entry's page fingerprint.
Caller input cannot supply an import URL. The entry also registers a pure main
thread runner without importing files or installing page message handlers.

Each request snapshots the basis, private/public comparison, settings, accepted
count envelopes, validated calls and optional open research views. Input values
stay in page/worker memory; they are not logged, persisted or uploaded. An opaque
epoch and exact model/context/frame identity accompany every response. The page
rechecks source admission, call validity, mode, settings and basis before a
single admission gate commits the complete result. The public comparison and
optional variants belong to the same frame. History and admission audit observe
only accepted frames.

One primary worker is owned at a time. Corrections, withdrawals, new or retracted
calls, context/settings changes and visibility loss cancel and terminate its
predecessor. Retained callbacks cannot commit. A narrowly compatible count-only
update can instead leave that worker running and replace one queued snapshot.
This avoids repeatedly discarding completed work when valid sources update in
staggered intervals. It does not admit an older calculation as the latest input.
The opt-in fictional rehearsal owns a
separate worker and never supplies live observations or live history. Closing it,
changing election mode, hiding the page or replacing model inputs invalidates
its request. Archive mode permits a fresh Home polling baseline with no live
calls or count envelopes.

## Pending and unavailable views

Changed inputs normally withhold previous model odds, winners and driver
claims before the existing refresh debounce. The count-only exception shows an
explicit **Last completed calculation** with its captured input version and
source clocks while newer returns process. The paired public comparison and
research views remain from that same completed frame. Exact latest-input
admission and the default controller ticket contract remain unchanged.

Compatibility requires identical basis, private/public context, options, model
revision, validated calls, source identities, geography and method contract.
Every typed candidate cell, including Nebraska's individual other candidates,
must be nondecreasing; changed counts require a newer source publication clock.
Both old and new envelopes must still pass installed admission at the current
time, checked again before commit and while a completed frame is displayed.
Decreases, unknown metadata and unsupported inputs retain immediate withholding.
The first slice supports only the16 installed civic county contracts. Official
WA/VA caches and remaining-ballot supplements retain the hard refresh path:
their shorter receipt and method-cell rules cannot be replaced by the broader
county publication-age check. This is not an all-source liveness guarantee.

Captured inputs remain in RAM. Existing local history records only whitelisted
derived results, source provenance and captured/completed clocks; it never
persists a basis, private input values or source bodies. Hard invalidation clears
the completed/queued references, labels and timer before replacement work.
Source counts, the validated call
ledger and celebration eligibility remain independent. Personal disclosure DOM
is retained, with obsolete derived content hidden and inert. The reader keeps a
semantic bookmark and scroll position; accepted results restore the same control
or its race heading when the explanation disappears. A user who moves away is
not pulled back. The national pointer is neutral while unavailable.

If workers or their static assets are unavailable, the same pure computation can
run synchronously with an explicit compatibility message. It retains all draws
and support gates and may block controls on a slow device. A 30-second worker
deadline withholds the frame; it does not retry that costly calculation on the
main thread or weaken the model. Source reporting continues. Optional research
failures do not replace the primary model. Prior-only correlation sensitivities
are unavailable when calls or county returns condition the current forecast.

Worker and main-thread results share a recursive admission guard. It rejects
nonfinite numbers, private proposal fields, typed buffers and output cycles
before current claims, history or audit can change. Legitimate acyclic aliases
are allowed. The same guard remains available when the optional controller or
worker script fails to load. Invalid county output can use the existing engine
fallback; that fallback must pass the guard too. Invalid final output is withheld.
Each optional research result is checked before bundle assembly, including its
fixed sample count, so malformed research output is quarantined without losing
the valid primary forecast or its paired public comparison.

## Evidence and limits

Unit and real-browser checks exercise exact synchronous/worker equality,
out-of-order callbacks, cancellation, private/public atomicity, static failures,
timeout withholding, lifecycle boundaries, keyboard reading and responsive
controls during a fictional 200-call calculation. These are engineering and
mathematical checks. Physical-phone performance, genuine post-close production
delivery and independent chronological predictive calibration remain separate
open gates. The separately reviewed resource-aware proposal in
SOURCE_CALL_CONDITIONING.md improves support in the fixed fictional 200-call
case without changing its target or hard support floor. Its complete private,
public and two-House-research worker frame is tested against the unchanged
30-second deadline. Other concentrated cases still withhold; neither background
execution nor these synthetic results guarantee full-night conditional learning.
