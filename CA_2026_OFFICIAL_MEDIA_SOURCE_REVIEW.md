# California's official 2026 Election Night media files — source research

The official November 3, 2026 general-election media portal at https://media.sos.ca.gov/ already lists eight concrete file identities: C26GG.txt (candidates), J26GG.txt (jurisdictions), P26GG.txt (county precinct counts), R26GG.txt (contest identifiers), S26GG.txt (counties), V26GG.txt (vote returns), and JSON/API endpoint catalogs (json-endpoints.csv and api-endpoints.csv). This is a promising P0 lead for California's 52 House districts outside the primary 22-state provider.

The source identity monitor checks only the official HTML index and never downloads those files. Some linked files may contain mock or old information before Election Day. A reference to an export link is NOT actual live source coverage, an official race call, a validated county denominator, or permission to republish media-client data. California SOS documents a distinct election media-client feed and API access: https://www.sos.ca.gov/media/.
